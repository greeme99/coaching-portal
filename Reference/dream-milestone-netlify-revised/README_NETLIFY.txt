Dream Milestone - Netlify 배포용 수정 최종 패키지

배포 방법
1. Netlify > Add new site > Deploy manually 로 이동합니다.
2. 이 ZIP 파일을 압축 해제합니다.
3. 압축 해제된 폴더의 전체 파일/폴더를 Netlify 업로드 영역에 드래그합니다.
4. 배포 후 생성된 URL로 접속합니다.
